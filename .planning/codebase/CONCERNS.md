# Technical Debt & Concerns

**Analysis Date:** 2026-10-18

## Technical Debt & Fragile Areas

### 1. Upstream Platform Bot-Protection (TeraBox & Meta)
- **Problem:** TeraBox web endpoints (`1024tera.com/api/share/list`) and Instagram/Facebook endpoints frequently update anti-bot challenge headers, reCAPTCHA, and Cloudflare challenges. Datacenter IPs from Vercel or AWS can be blocked.
- **Current Mitigation:**
  - Fallback offline / sample resolver engine.
  - Client-side prioritization: YouTube thumbnails and transcripts avoid heavy proxy requirements because Google provides public CDN endpoints and standard timedtext tracks.
- **Future Improvement:** Configure a rotating residential proxy pool or headless worker if automated high-volume server-side scraping of TeraBox streams is needed.

### 2. YouTube Closed Caption Availability
- **Problem:** Not all YouTube videos have closed caption tracks uploaded or auto-generated by YouTube (e.g., pure music or non-dialogue clips).
- **Current Mitigation:** Honest state handling: UI displays an informative notice ("No closed captions found for this video") and allows users to load sample cues if they want to preview the transcript features.

### 3. Client Ad Blocker Interference
- **Problem:** Browser extensions (uBlock Origin, Brave Shields) block external ad scripts (`Monetag`, `Adsterra`) and can collapse empty DOM elements.
- **Current Mitigation:**
  - Minimum container heights and discrete placeholder formatting in `AdBannerSlot.tsx` to prevent Cumulative Layout Shift (CLS).

### 4. Legacy Artifacts & Cleanup
- **Problem:** Repository still contains legacy anime scraping scripts (`scripts/scraper.mjs`, `scripts/split-lore.mjs`) and old SQL schemas from the previous Donghua streaming prototype.
- **Current Mitigation:** `src/App.tsx` redirects all legacy paths to `/`, and `src/pages/Index.tsx` is completely isolated from the legacy anime components.
